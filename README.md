## Architecture & Standards

- **Hosting:** GitHub Pages static architecture

- **Indexing:** Centralized `sitemap.xml` with automatic search crawler discovery
- **E-E-A-T Transparency:** Medical disclaimers, editorial policies, and transparent affiliate disclosure statements on every review page.
